A big tidy-up of the first alpha: safer, easier to read, and nicer to look at.

## New

- **Better logs.** Search them (Ctrl+F), jump between matches, show only the errors, and turn on word wrap. Lines are numbered, and log files open in the same viewer.
- **Environment, redone.** See every `.env` file in your project, edit any of them, and drag the list into the order you like.
- **Report a bug** in Settings and the tray menu opens a GitHub form with your version filled in.
- **Keyboard shortcuts:** F5 starts everything, Shift+F5 stops it, Ctrl+Shift+F5 restarts it, and Ctrl+S saves in the editors.
- **The window remembers** its size, position and layout.
- **Get Dev builds** turns itself on if you install a test version.

## Looks

- The real Dev Runner icon in the window and by the clock.
- Dark menus and dark pop-ups everywhere, instead of plain Windows ones.
- A tidier header, buttons that say why they're greyed out, and Stop no longer looks dangerous.
- Update problems are explained in plain words.

## Fixes

- Dev Runner no longer stops programs it didn't start, such as your own Visual Studio or dotnet runs, or something else using a port.
- Your project list can't be wiped by a settings file that's locked or has a typo, and a broken settings file for one project isn't thrown away.
- "Restart up to N times" now really restarts N times.
- A crashed app no longer shows as "Build failed".
- Saving variables restarts each service once, not twice.
- Updates never offer an older version.
- Managed builds catch every change, including deleted and renamed files, and no longer slow down other builds on your PC.
- Logs are lighter on the disk and the screen, and Dev Runner does less work while it's hidden.
- A failed update no longer freezes the app.
